# Applied Machine Learning in Empirical Finance

A PhD research project at the **[University of Twente](https://www.utwente.nl/)** in collaboration with **[Quoniam Asset Management](https://www.quoniam.com/)**.

[Visit the project website](https://digital-ai-finance.github.io/Applied-Machine-Learning-in-Empirical-Finance/)

## Research focus

The project investigates how machine learning and alternative data, including financial text, can improve the explanation and prediction of asset returns and inform portfolio construction under realistic market frictions.
