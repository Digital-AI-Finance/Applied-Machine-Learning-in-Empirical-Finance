Tools

Open-source tools I developed for research

LaTeX Claim & Bibliography Checker

Checks a LaTeX manuscript before submission. It compares each cited BibTeX entry with Crossref, OpenAlex and DataCite and asks a language model whether the abstract of each cited work supports the citing sentence. Runs locally with LM Studio. A verification aid based on abstracts.

Python 3.11+ · Markdown or Excel report · latex-claim-and-bib-checker
